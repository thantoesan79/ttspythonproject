# 🚀 Python Intensive Course - 5 Projects Overview
Tech4U မှ ပို့ချသော Python Intensive Course တွင် လက်တွေ့တည်ဆောက်ခဲ့သည့် Project (၅) ခု၏ စုစည်းမှု ဖြစ်ပါသည်။ အခြေခံမှစ၍ Object-Oriented Programming (OOP) အထိ လေ့လာသင်ယူခဲ့သော အဆင့်များကို ဤနေရာတွင် ကြည့်ရှုနိုင်ပါတယ်။

---

## 📂 Projects List

### 1. 💰 Personal Budget Tracker
ဝင်ငွေနှင့် ထွက်ငွေများကို စနစ်တကျ မှတ်တမ်းတင်ပေးသည့် Program ဖြစ်ပါတယ်။
* **Key Learning:** File Handling (CSV), Basic Data Types, User Input Validation.
* **Functionality:** ဝင်ငွေ/ထွက်ငွေ ထည့်ခြင်း၊ Balance တွက်ချက်ခြင်း၊ Report ထုတ်ခြင်း။

### 2. ⏰ Interactive Quiz Game
အချိန်သတ်မှတ်ချက်ဖြင့် ဖြေဆိုရသော Quiz Game တစ်ခုဖြစ်ပါတယ်။
* **Key Learning:** `time` module, List of Dictionaries, Control Flow.
* **Functionality:** Countdown ပြသခြင်း၊ ကြာချိန်တိုင်းတာခြင်း၊ ရမှတ်တွက်ချက်ခြင်း။

### 3. 📝 To-Do List Manager
နေ့စဉ်လုပ်ငန်းဆောင်တာများကို ဦးစားပေးအဆင့်အလိုက် စီမံခန့်ခွဲပေးသည့် Program ဖြစ်ပါတယ်။
* **Key Learning:** Custom Delimiters, Lambda Functions (Sorting), `datetime` module.
* **Functionality:** Task များထည့်ခြင်း၊ Priority အလိုက် စီခြင်း၊ ဖျက်ခြင်း။

### 4. 🌦️ Weather Data Analyzer
မြို့အလိုက် အပူချိန်ဒေတာများကို ခွဲခြမ်းစိတ်ဖြာပေးသည့် Data Tool တစ်ခုဖြစ်ပါတယ်။
* **Key Learning:** Data Grouping, Statistical Functions (`max`, `min`, `avg`), Error Handling.
* **Functionality:** CSV မှ ဒေတာဖတ်ခြင်း၊ မြို့အလိုက် အကျဉ်းချုပ် Report ထုတ်ခြင်း။

### 5. 📱 Contact Book Manager (OOP)
Object-Oriented Programming Concept ကို အသုံးပြု၍ တည်ဆောက်ထားသော Contact Book ဖြစ်ပါတယ်။
* **Key Learning:** Classes & Objects, Constructor (`__init__`), Data Synchronization.
* **Functionality:** Contacts များသိမ်းဆည်းခြင်း၊ ရှာဖွေခြင်း၊ Update လုပ်ခြင်း။

## ⚙️ How to Setup
ကိုယ့်စက်ထဲတွင် စမ်းသပ်ကြည့်ရန် အောက်ပါအတိုင်း ပြုလုပ်နိုင်ပါတယ်။

1. Repository ကို Clone လုပ်ပါ။
​```bash
git clone 
​```

2. Project တစ်ခုခု၏ Folder ထဲသို့ ဝင်ပါ။
​```bash
cd project-folder-name
​```

3. Python ဖိုင်ကို Run ပါ။
​```bash
python main.py
​```
